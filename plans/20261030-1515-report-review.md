# Account Report Review And Tracker UI

## Scope
- Preserve concurrent search-history edits. No deployment. External read-only
  HenrikDev/public-asset access was explicitly approved for final verification.
- Reuse local tracker.gg tokens, Saira headings, v3-card surfaces, stat tiles,
  compact striped tables, muted labels, and semantic red/green/gold accents.

## Confirmed Defects
- Empty evidence produces audit 45; unknown level produces alt 38.
- Thirty stored rows bypass the roster gate and can produce an alt verdict.
- Lifetime stats and selected-act rosters compare against today's rank.
- Arbitrary model constants are presented as probabilities and a 90% CI.
- Draws count as losses; rename matching loses the owner after a rename.
- Missing clusters penalize history; truncated history is treated as account age.
- Audit alone performs up to 50 unnecessary detail fetches.

## Plan
1. Account-wide Competitive audit; recent, deduplicated Competitive rosters for
   diagnosis. Hide irrelevant ACT/mode filters on these two tabs.
2. Explicit minimum evidence, null unavailable outputs, PUUID identity, valid
   teams/rounds/ranks, correct draws, chronological opponent ranks.
3. Historical changes are descriptive, not ownership probabilities. Stat
   outliers cannot establish cheating. Rank estimate is a heuristic model range,
   never a calibrated confidence interval/probability distribution.
4. Rebuild both panels with shared report primitives and scoped responsive CSS.
5. [x] Regression tests, local rendered UI at desktop/mobile, lint/type/build.
6. [x] Document formulas, limitations, and actual validation.

## Result
- All steps implemented. Diagnosis uses at most 10 top-up match IDs only when
  the recent minimum is missing; audit never fetches details.
- 116 tests pass; lint/typecheck, Next and OpenNext builds pass.
- Real Meiy/ashrielle pages verified, EN/JA, desktop/mobile with no page overflow.
- Full review: `docs/reports/20261030-account-report-review.md`.
- No deployment/notification/production database changes or commit in this task.
